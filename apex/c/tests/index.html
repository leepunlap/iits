注：

1、線上考試是指考生自行準備考試場地及電腦等設備，在指定時間（以准考證為準）通過網絡登錄考試及監考系統進行考試並接受遠程監考，不受地域限制。

YAI青少年人工智能技術水平測試 題型、分值分佈（含線上答辯要求）

一、題型、分值分佈

理論、實操分別合格表示考試通過，有一門或兩門不合格則不通過。

二、實踐操作考試線上答辯影片錄製要求（不超過3分鐘）

一級：

提交實操試卷後，請錄製一個不超過3分鐘的答辯影片。要求： 1、首先介紹自己的姓名、准考證號和考試級別。2、説出已搭建完成的作品的名稱，並簡述其結構主要有哪些關鍵部分組成。3、結合搭建題目的要求，對自己的作品進行簡單介紹。

二級、三級、四級：

提交實操試卷後，請錄製一個不超過3分鐘的答辯影片。要求： 1、首先介紹自己的姓名、准考證號和考試級別。 2、説出已搭建和編程完成的作品的名稱，並簡述這個作品的組成部分及各自的功能。 3、結合第1題和第4題的要求，對作品進行簡單介紹。

五級、六級：

提交實操試卷後，請錄製一個不超過3分鐘的答辯影片。要求： 1、首先介紹自己的姓名、准考證號和考試級別。 2、説出智能小車的任務完成情況。 3、結合任務要求，對作品進行簡單介紹。

SCL青少年科技素養水平測試 一級案例範圍

小橋、遮陽棚、吸水杯、菜籃、三角形邊框

一、實驗任務：小橋

實驗材料：可以滿足實驗任務的相關器材。

實驗要求：

1. 利用材料製作一款小橋，兩個橋墩之間的距離是一張A4紙的長度

2. 測試並記錄小橋能夠承載的硬幣數量

3. 改進小橋，讓其能夠承載更多硬幣

4. 記錄改進後的小橋能夠承載的硬幣數量

二、實驗任務：遮陽棚

實驗材料：可以滿足實驗任務的相關器材。

實驗要求：

1. 利用材料製作一款遮陽棚

2. 遮光效果好，遮陽棚比較穩固

3. 測試遮陽棚的遮陽效果，能夠擋住手電筒的光

4. 改進遮陽棚，讓其遮光效果更好

三、實驗任務：吸水杯

實驗材料：可以滿足實驗任務的相關器材。

實驗要求：

1. 利用材料製作一款吸水杯

2. 記錄吸水杯花盆能把水吸到小花根部的距離

3. 改進吸水杯花盆，讓其儘可能多的將水吸到小花根部

4. 記錄改進後的吸水距離

四、實驗任務：菜籃

實驗材料：可以滿足實驗任務的相關器材。

實驗要求：

1. 利用材料製作一款菜籃

2. 測試並記錄菜籃能裝幾個砝碼

3. 改進菜籃，讓其能夠裝更多砝碼

4. 記錄菜籃改進後能夠裝的砝碼數量

五、實驗任務：三角形邊框

實驗材料：可以滿足實驗任務的相關器材。

實驗要求：

1. 利用材料製作一個四邊形邊框

2. 按壓四邊形邊框，測試其是否具有穩定性

3. 改進模型，製作一個三角形邊框

4. 測試三角形邊框是否具有穩定性

青少年無人機技術水平測試

青少年無人機技術水平測試用於考查應試人員的無人機基本知識、程序思維、編程語言、無人機基本操作等，主要人羣為青少年（包括但不限於中小學生、大學生及從業人員)。

青少年無人機技術水平測試分三等(初等、中等和高等)五級(一至五級)，一級可進行跳級，二級及以上級別需逐級進行測試。為廣大應試人員的升學、實習、進修等提供在無人機方面能力水平的證明。

一、證書發放單位

（一）工業和信息化部教育與考試中心

工業和信息化部教育與考試中心是經中央機構編制委員會辦公室批准設置的事業單位，在工業和信息化部領導下，承擔工業、通信業和信息化系統專業人才培訓及相關資格考試的有關工作。

（二）中國電子教育學會

五、項目特色

1、青少年無人機技術水平測試涵蓋無人機所需要的知識和技能，以理論加實踐應用能力為主。所有考核內容分了解、理解和掌握三個層次，瞭解指對該項內容有初步的認知，理解指具備基本的知識結構，可以在實操中運用該項內容的知識，掌握指具備系統的知識和應用能力。在具體的項目實施過程中，通過學生的動手操作，對學生對技術的掌握和運用能力做出評價。

具體如下：

知識層面

（1）對無人機的基本知識掌握程度；

（2）以遙控、編程為主的無人機飛行控制知識掌握程度；

（3）以無人機搭載設備為主的傳感器知識掌握程度；

（4）以無人機飛行模塊和基本邏輯、數學、變量為主的圖形化編程類知識掌握程度；

（5）以數據抽象和算法設計為主的代碼編程類知識掌握程度；

（6）對跨學科知識的綜合應用知識層面；

思維及表達層面

（1）在學習過程中具有敏捷的思維組織能力；

（2）在算法設計中流程圖的運用能力；

（3）計算思維在不同學科中應用的能力；

（4）分析有效資訊及其是否全面的能力；

（5）建立跨學科知識和視野的能力；

（6）在飛行控制過程中，具有清晰準確的語言表達能力能力；

（7）在飛行控制過程中，可以根據複雜環境具有臨場應變能力；

技術層面

（1）掌握無人機飛控系統、動力系統原理；

（2）掌握無人機各部分組件功能應用，具有無人機的保養與維修能力；

（3）掌握空氣動力學基礎與無人機的飛行原理；

（4）熟練掌握無人機操控技術，能夠根據現場要求完成複雜的無人機飛行控制；

（5）根據飛行任務，使用軟件中的命令進行程序編輯，控制驅動無人機完成指定飛行操作；

（6）能夠繪製流程圖並根據流程圖編程控制無人機完成綜合飛行任務；

2、以編程所必備的工程思維和計算思維為基礎，側重學生全方位的綜合能力評價。
